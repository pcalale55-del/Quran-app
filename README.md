# تطبيق القرآن الكريم — النسخة الأولى

هذه نسخة ويب بسيطة تعمل مباشرة في المتصفح.

## التشغيل
افتح `index.html` في المتصفح.

> تحتاج الصفحة إلى اتصال بالإنترنت لتحميل نص السورة والصوت من خدمة Al Quran Cloud.

## الموجود في النسخة الأولى
- قائمة السور الـ114
- البحث باسم السورة أو رقمها
- قراءة السورة
- RTL والعربية
- الوضع الليلي
- حفظ آخر سورة
- متابعة القراءة
- تشغيل تلاوة السورة (مشاري العفاسي)

## مصدر البيانات
يستخدم التطبيق Al Quran Cloud API للنص القرآني وCDN للصوت.
المشروع ليس تابعًا لـ Al Quran Cloud.

## الخطوات القادمة
- البحث داخل الآيات
- المفضلة والعلامات المرجعية
- حفظ آخر آية بدقة
- اختيار القارئ
- التحكم بالتلاوة آية بآية
- الأذكار
- الختمة
- تحسين PWA وإضافة التثبيت على الهاتف


## تثبيت على الهاتف (PWA)
بعد رفع مجلد المشروع على موقع يعمل عبر HTTPS:
- Android/Chrome: افتح الموقع ثم اختر "تثبيت التطبيق" أو "Add to Home screen".
- iPhone/Safari: افتح الموقع ثم مشاركة → "إضافة إلى الشاشة الرئيسية".

## APK
النسخة الحالية PWA. تحويلها إلى APK يحتاج عملية بناء Android (يمكن تنفيذها لاحقًا عبر خدمة بناء سحابية أو Android Studio).
